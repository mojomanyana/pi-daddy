# ADR-0050 — Bounded manual debrief, genuine host labels and quality-first reveal

Date: 2026-09-08
Status: Local implementation; overall review/acceptance and live integration pending

Extend the existing dashboard/plugin rather than adding a product or a dashboard decision ledger. Pin
actual harness4460af9 work-case/review and0475e1f intervention fixtures. The presenter validates cases and
history, captures host-selected reviewer/identity callbacks, and delegates labels to the actual harness
writer. Missing writer, identity or host checkpoint disables actions; skip/unselected remain unresolved.

A host-owned attention/transport checkpoint reserves at most five total slots before exposure. A blind
comparison uses one slot, not an extra page. Scope/offset/card IDs/blind digest stay fixed across close,
answer and reopen; none refunds allowance. Another explicit host presentation is needed for another page.
Label requests persist before their one writer call; stale/unknown replies require history readback, never
implicit resubmission. Case decisions remain solely in harness-owned history.

Opaque labels and verified retained artifact previews precede any configuration/cost reveal. Quality choice
and reveal-attempt state are checkpointed; choice confirmation precedes reveal, and changed choices lock.
Known synthetic A/B captions are removed; arbitrary text may still disclose identity. The public zero-seed
fixture is not a real blind study. Host identity/private seed persistence remain external responsibilities.

Standalone CLI fixture mode and programmatic host ports use the same actual render/action path. Own-dashboard
input never becomes worker prompts or terminal steering. Read-only frames do not write or reconcile. The
existing plugin flag is explicit and participates in reuse identity; no writer loader is added.

Automatic presentation is unqualified and always deferred. Agent_end, guessed idle/file tail and even a
caller string claiming a closing pause cannot replace genuine closing-pause/user/policy/writer qualification.
No model calls, per-task model reviews, package lifecycle or publication is introduced. Real pinned host
writer/blind methods run only in owned fixtures; that is not installed/live qualification.

Integration contract: packages/pi-daddy/contracts/debrief/v1. P05 owned cancellation remains implementation
work; general live steering and P02/P04/P06 limitations remain. Stop for the next ready batch clause.
