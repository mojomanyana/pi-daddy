## Decision

Use the EXISTING dashboard CLI/Herdr plugin and actual producer intent/resource/experiment controllers.
Use the exact LOCAL harness1c02194d4a3709d14890a5fbbad91ff5f0151f65 journal/trust/case/blind/archive modules.
No second learning-decision store, scheduler, model host or worker monitoring hook is introduced.

- Ordinary delegate/all/chain planning has explicit host-only native-session retention opt-in. It allocates
  private per-execution targets before plan/audit, leaves default ephemeral behavior unchanged, and never
  reads a session path from model tool fields. Existing retention remains asynchronous/bounded and native
  file observations still do not establish a TUI active branch or final transcript completeness.
- Explicit durable host source jobs call actual approved archive policy/checkpoint ingestion. Registered
  fact files, retained Work-v4 bytes and actual native manifest/blobs reach real semantic signal/execution
  projection and the existing daily reader. Fact declarations remain declarations, bound to exact source
  bytes/scope, not authenticated truth. Missing/partial/corrupt source bytes remain gaps; selection failure
  withholds acceptance/steering but need not prevent retaining incomplete observation bytes.
- The shared genuine learning journal holds only host requests/transport checkpoints/presentation metadata.
  It is at one fixed child of the registered trust directory. Existing trust.expose reserves up to five
  TOTAL case/blind slots before checkpoint/exposure. Reconnect never selects another store/refills a policy.
  Case population/version is checked against the predeclared policy. Silent/exhausted policy defers weekly;
  a failed required write is different, failed/unknown with any charged/observable effects preserved.
- Actual existing manual presenter/writers load and reconnect. A prepared frame is not delivered-human
  evidence; explicit independently approved presentation acknowledgement must match the current frame,
  original pause revision and current independently sourced presence declaration. Reads hide absent/stale
  cards without steering. Labels/quality/reveal use original writers; action returns now preserve unknown
  label acknowledgements rather than dropping them in a void UI wrapper. No automatic quality or reveal.
- Dashboard requests carry whole-request independent approval, immutable IDs, exact host/source selection
  and journal-tip CAS. Native request revision/CAS/non-expansion checks remain load-bearing. Busy resource
  pause stays pending until explicit reconciliation. Scope/priority/recorded alternative route through P01;
  legacy cancellation is bridged to the separately approved ORIGINAL experiment handle. Refresh/reconcile
  never dispatches, retries, aborts or writes. Required host failures persist separately from worker results
  wherever possible; failure-recording can itself fail. No refund, takeover or implicit effect replay.
- The private bounded Unix socket connects the ordinary existing dashboard process to the actual owning
  host; it does not reconstruct controller ownership in the UI process. Client timeouts/disconnects remain
  unknown acknowledgement. There is no raw Herdr/terminal typing fallback or PID/name-based target recovery.

## Artifact identity and scope

A public bounded artifact loader checks actual compiled file bytes and stages them into a fresh private
module tree, avoiding stale module-cache identities. New host instances require that original loaded API
and its independently approved artifact digest, not caller-spread interface lookalikes. The37 exact pinned
source bodies in ordinary fixtures compile and execute real native archive, journal, trust and decision
code. Typebox is the explicitly retained peer; its package metadata is bound, not its full source graph.
This does NOT authenticate a human/module or provide hostile same-UID/code confinement. Deployed artifact
provenance/consent and atomic live pause/user presence remain independently required B/C evidence.

No host telemetry redactor or export/deletion mechanism is improvised. Exact access/ingestion policy and
expiry are applied, redacted/reference-only content cannot masquerade as exact replay, but remaining P03.4
redactor/retention-duration/credential-safe reviewed export operations require the concrete harness-owned
adapter described in the contract. Existing historical content is untouched. Likewise wider P01 entity /
topology revisions, generalized ordinary-child cancellation and arbitrary live TUI atomic steering are not
qualified by the bounded original P11 bridge. These limits are not relabelled successful implementation.
